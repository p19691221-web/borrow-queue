# 借用排隊板

這是一個給服務台用的小工具，可以登記推車、輪椅或其他物品的借用和排隊。

- 東西借完時，替客人登記排隊（需要留手機）。
- 有人歸還，畫面會跳出「請通知下一位」，一鍵打電話或傳簡訊，簡訊內容已經填好。
- 通知後開始倒數保留時間，可以標記「已領取」或「沒來」。
- 「今日紀錄」會自動統計借出次數、排隊人數、平均等待時間，以及每小時的借出量；可以匯出 CSV，也可以選擇去除個資後匯出。
- 支援加到手機桌面，打開就像 App。

網址：https://p19691221-web.github.io/borrow-queue/

## 資料與隱私

- 所有資料只存在這台裝置的瀏覽器裡，不會上傳到任何伺服器。
- 一個服務台用一台手機或平板。換一台裝置就看不到資料，清除瀏覽器資料也會一起刪除。
- 名單上的電話只顯示後三碼。
- 建議每天結束時先匯出，再到「今日紀錄」按「結束今天」清除。

## 用手機上架（GitHub 網頁版）

1. 在 GitHub 建立公開 repo，名稱 `borrow-queue`。
2. 進入 repo，點「Add file」→「Upload files」，一次選擇這 8 個檔案：
   `index.html`、`manifest.webmanifest`、`sw.js`、`icon-192.png`、`icon-512.png`、`icon-maskable.png`、`apple-touch-icon.png`、`README.md`
   上傳前先確認檔名沒有被手機改成 `index-1.html` 之類的名稱。
3. 按「Commit changes」。
4. Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main` / `(root)`，按 Save。
5. 等 1–2 分鐘，打開 https://p19691221-web.github.io/borrow-queue/

## 加到手機桌面

打開網址後按右上角「加到手機桌面」。

- Android（Chrome）：會跳出安裝視窗，按「安裝」。
- iPhone：用 Safari 打開，按下方「分享」→「加入主畫面」。
- 在 LINE 或臉書裡打開時，先選「用瀏覽器開啟」。

## 第一次使用

到「設定」填物品名稱、總數、領取地點、保留幾分鐘，按「儲存設定」。簡訊內容可以自己改，`{名字}`、`{物品}`、`{地點}`、`{分鐘}` 會自動換成實際內容。

## 限制

- 打電話和傳簡訊是開啟手機本身的撥號和簡訊 App，用的是那台手機的門號，會照一般費率計費；平板沒有門號就只能看電話自己撥。
- 單機版：多個服務台要共用同一份名單，需要另外接資料庫（例如 Supabase），目前沒有做。
- 客人不能自己掃 QR Code 登記，只能由服務台人員輸入。
